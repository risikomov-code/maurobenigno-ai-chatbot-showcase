# Public Showcase / Security Boundary

This repository is intentionally **not** a deployable copy of the production chatbot.

## Public

- business problem and use case
- high-level architecture
- integration patterns
- validation and guardrail concepts
- non-sensitive technology stack
- portfolio case-study narrative

## Private

- API credentials and tokens
- server and infrastructure addresses
- production source code
- system and developer prompts
- exact knowledge-base content
- retrieval configuration
- embeddings or vector-store details
- private business rules
- lead and conversation data
- analytics
- webhook URLs
- model and provider configuration
- deployment scripts and environment variables

No production secret, personal data or proprietary knowledge-base content should ever be committed to this repository.
